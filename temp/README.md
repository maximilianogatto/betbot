# temp/

Carpeta para archivos **temporales y descartables**: respuestas HTTP capturadas,
volcados de red, HTML de prueba, snapshots de investigación, experimentos sueltos.

Reglas:

- Todo lo que cae acá está **ignorado por git** (salvo este README y `.gitkeep`).
- No pongas acá nada que aporte al proyecto: si sirve, va al código o a
  `sandbox/<extractor>/` con su `HALLAZGOS.md`.
- Se puede borrar entero en cualquier momento sin perder nada importante.

Ejemplos de lo que va acá: `active_response.bin`, `all_responses.json`,
`captured_requests.json`, dumps de Playwright, capturas crudas de odds.
